# DealVerify

Only real deals. Verified.

DealVerify is an India-first, mobile-first PWA concept for high-signal deal alerts. A deal should reach the user only after price, pincode availability, and recent-value checks pass.

## Current slice

- Mobile-first onboarding
- 6-digit pincode setup
- Configurable high-priority threshold (₹500 default)
- Persistent local settings
- Verified-feed empty state
- Mock verified deals for UI validation
- Settings screen
- PWA manifest
- DealVerify visual system from the product brief
